# Lost in the Dark Forest 🌲

A text-based choose-your-own-adventure game built using GitHub Copilot.

## How to Play

```bash
python game.py
```

Read the story, pick a numbered option, and see where it takes you. 6 possible endings — 3 wins, 3 losses.

## Built With

- Python
- GitHub Copilot (MLH Global Hack Week challenge)
